# وب‌سایت شخصی مهدی لشگری — نسخه استاتیک

سایت دوزبانه (فارسی / انگلیسی) با HTML، CSS و JavaScript خالص. بدون فریم‌ورک، بدون npm و بدون مرحله build. همه مسیرها نسبی هستند و سایت مستقیماً روی GitHub Pages کار می‌کند.

## ساختار

```
index.html            نسخه فارسی (ریشه، راست‌چین)
about.html            درباره من
resume.html           رزومه و تایم‌لاین تحصیلات و سوابق
inventions.html       اختراعات
publications.html     مقالات
awards.html           جوایز و افتخارات
conferences.html      همایش‌ها و سخنرانی‌ها
gallery.html          گالری تصاویر با نمایش بزرگ
blog.html             فهرست مطالب وبلاگ
blog-post.html        صفحه نمونه مطلب
downloads.html        دانلودها
contact.html          فرم تماس (بدون ارسال واقعی)
search.html           جست‌وجوی داخلی روی data.json

en/                   نسخه انگلیسی، همان صفحات با نام یکسان
css/style.css         استایل مشترک هر دو زبان
js/main.js            منو، هدر چسبان، گالری، اسلایدر گواهی‌ها، شمارنده آمار، ظاهر شدن نرم، فرم تماس و جست‌وجو
data.json             داده جست‌وجو (اختراعات، مقالات، مطالب)
assets/img/           تصاویر فشرده‌شده برای وب
assets/docs/          رزومه و گواهی‌های PDF
assets/fonts/         فونت‌های Vazirmatn و Inter (self-hosted)
```

## تبدیل به قالب PHP

هدر و فوتر در همه صفحات عیناً یکسان‌اند و با کامنت مشخص شده‌اند:

```
<!-- شروع هدر مشترک — برای تبدیل به include -->
<!-- پایان هدر مشترک -->
<!-- شروع فوتر مشترک — برای تبدیل به include -->
<!-- پایان فوتر مشترک -->
```

برای مهاجرت، محتوای این دو بلوک را در `header.php` و `footer.php` بگذارید و با `include` جای‌گذاری کنید. لینک‌های منو در فایل `index.php` با تابع تشخیص صفحه فعال می‌شوند و مسیر زبان با یک متغیر ساده تغییر می‌کند.

نسخه فارسی در ریشه و نسخه انگلیسی در `en/` است؛ دکمه تغییر زبان در همه صفحات به صفحه معادل می‌رود. برای دامنه اصلی کافی است هاست را به ریشه پروژه تنظیم کنید.

## جای خالی‌ها

هر داده‌ای که در `content/` موجود نبود، با نشانه‌ای مشخص در متن باقی مانده است (مثلاً `[شماره ثبت اینجا]`). این نشانه‌ها با استایل `.placeholder` در CSS قابل جست‌وجو و جای‌گذاری هستند. موارد باقی‌مانده:

- شماره ثبت اختراعاتی که فقط گواهی مسابقه دارند
- سال شروع دوره دکتری و سوابق شغلی
- نشانی ایمیل و نمایه Google Scholar
- نسخه PDF رزومه
- عنوان جلد دوم کتاب و سال دریافت نشان ASIDE
- متن مطالب وبلاگ
